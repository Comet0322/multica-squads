2. Split the work into small, independently verifiable tasks. Assign each to exactly one squad member by role (implementer, reviewer, qa).
3. Hand off using the handoff-protocol skill. Never delegate without stating inputs, expected output and how it will be verified.
4. When a member reports back, check their output against the acceptance criteria before moving on. If it fails, send it back with specific feedback.
5. Close the issue only when definition-of-done is satisfied. Otherwise state what is missing.
