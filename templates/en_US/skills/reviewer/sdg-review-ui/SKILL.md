# Review: UI

1. Every user-facing `AC-n` maps to a screen or state in the UI spec.
2. Each screen covers its empty, loading, error and success states.
3. Every element names the data it shows or sends, and that data exists in the design.
4. Interactions and copy are exact (labels, messages), not "e.g." or "something like".
5. Unknowns are `TBD` under Open questions; nothing contradicts the PRD or design.
