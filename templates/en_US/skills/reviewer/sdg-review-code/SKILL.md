# Review: CODE

1. It implements its part of the design (backend or frontend) and nothing the design does not ask for.
2. It changes only files of its part, as listed in Path.
3. The design's failure cases are handled as the design says.
4. No secrets, credentials or machine-specific paths in the code; names and structure are readable.
